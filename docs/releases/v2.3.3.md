# v2.3.3 发布说明

v2.3.3 汇总自 v2.3.1 之后的 v2.3.2 和 v2.3.3 源码变更；v2.3.2 未单独创建 GitHub Release。MCP Server 与 EDA Bridge 应同时升级到 v2.3.3。

## v2.3.2：连接与写入恢复

- 原理图器件放置、导线和 NetPort 操作增加当前图页及连接状态回读；交互放置会等待退出放置模式，识别重复器件和位号变化。
- PCB 新增按网络创建直线导线与过孔的工具，并改进自动布局、自动布线超时后的完整状态回读。
- PCB 变更导入打开原生确认框后会暂停写入；确认应用或取消并完成同板回读后才恢复。多页面客户端选择增加待命页面探活。
- 断线、原生超时或提交状态不明时保留诊断，阻止重复写入；恢复绑定执行时的图页、文档或 PCB 身份。

## v2.3.3：更完整地操作 EDA

- 新增 `editor_navigate`，在当前工程打开或激活原理图图页与 PCB，并核对目标文档就绪及标签身份。
- 新增原理图普通器件、导线和文字的完整读取与受控编辑；复制图页共享图元 ID 时，读取和删除以实际当前页为准。
- 新增 `pcb_read` 语义快照，以及 PCB 器件、布线、覆铜、板框、区域、文字、文档目录和铜层管理工具；写入后回读实际结果。
- PCB 变更导入会在调用原生 API 前检查文档身份及所属板；交互放置、NetPort 移动、自动布线诊断和无网络 PCB 图元的回读得到修复。
- 大图页读取和受控恢复可设置更长的超时预算；`project_info` 在 PCB 页面仍能列出工程内原理图图页。
- Agent 指引按任务范围选择专用工具与输出深度；器件已确定或代选已获授权时不重复确认，精确 API 签名已验证时不重复检索。电源/地 NetFlag 可由 `netlabel_place` 放置，未知写入仍须按原流程恢复。
- 修复导线创建后图元列表延迟更新造成的误报；有界回读遵守任务超时预算，原生调用已结束但回读暂不可见时不再误要求重启 EDA 宿主。

## 安装与兼容

- 使用 Node.js 20 或更高版本。安装匹配的 `jlceda-mcp-server-2.3.3.tgz` 和 `mcp-bridge-community-2.3.3.eext`，并在 EDA 扩展管理器中启用“允许外部交互”。
- 本版扩展仅声明支持嘉立创 EDA 专业版 3.x，已在 3.2.181 / EDA API 0.3.15 上验证；v4 需等待未来兼容版本。
- 普通网络标签依赖 EDA v4 才提供的 `createNetLabel`，因此本版在 3.x 中立即报告不支持；电源和地网络标识仍可使用。

详细变更见 [Bridge 更新日志](../../mcp-bridge/CHANGELOG.md)和 [Server 更新日志](../../mcp-server/CHANGELOG.md)。社区版基于 [sengbin/JLCEDA-MCP](https://github.com/sengbin/JLCEDA-MCP) 改进，并非嘉立创官方插件。
